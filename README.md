# Abhi Agency Sales Dashboard

A sales dashboard for Abhi's agency built with Floot.

## Features
- Revenue and pipeline overview
- Probability-weighted pipeline
- Deals in progress
- Recent leads with search and filtering
- Add lead workflow
- Profile settings
- Light/dark theme
- Responsive layout

## Source
The application source is maintained in the connected Floot project and this repository contains the exported project snapshot.
